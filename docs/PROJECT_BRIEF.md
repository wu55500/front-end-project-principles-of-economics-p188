# 项目说明书 (PROJECT BRIEF)

## 一句话定位
把曼昆《经济学原理》第 9 章「不公平竞争论 / 出口补贴」做成一个可交互、可验证、可部署、移动端可用的教学网页。

## 问题与用户
- **问题**：纯文字 + 静态图难以让初学者直观理解「出口补贴 → 价格/产量/福利变化 → 转口贸易 → 报复/禁止进口」的因果链。
- **目标用户**：经济学初学者；同时作为作者面向 Java 后端 / Agent 开发岗位的全栈作品集。
- **使用场景**：手机浏览器（主要）与桌面浏览器访问线上站点，按章节顺序学习并动手操作。

## 项目层级（诚实标注）
当前为 **portfolio deployment（作品集级部署）**：单机 Docker + Nginx 反向代理，面向演示与教学，非高并发生产系统。数据基准来自公开权威来源，波动部分为教学模拟。

## 用户旅程
1. 故事引入 → 2. 供需福利图（拖 t 滑块实时联动）→ 3. 3D 沙盘 → 4. 三维地球（点击航线看实时数据）→ 5. 真实数据面板（世界银行，2005–2024）→ 6. 因果推断（DID / Granger）→ 7. 三种选择福利账 → 多人协同 / 助教 / 测验 / 总结。

## 功能需求（可追溯）
| ID | 需求 | 验收 |
|---|---|---|
| FR-1 | 补贴福利分析图，实时显示消费者/生产者/外国补贴/净福利 | 拖 t，矩形与数字联动；t=20 净福利 +400 |
| FR-2 | 3D 贸易沙盘，固定字号与角色配色 | 缩放后标签清晰不失色 |
| FR-3 | 三维地球，航线可点击、数值实时变化 | 三航线芯片 ▲▼ 跳动；点击出详情面板 |
| FR-4 | 真实世界数据，20 年均值 | 面板显示最新值 + 2005–2024 均值 |
| FR-5 | 因果推断教学（DID/Granger） | 改输入即时重算，含操作引导 |
| FR-6 | 三种选择福利对比 | 切换情景、拖 t 联动 |
| FR-7 | 移动端稳定（黑屏/显存/context lost） | 低端机可加载、不崩溃 |
| FR-8 | 安全防护与可复现部署 | 见 docs/SECURITY_MODEL.md |

## 非功能需求
- **NFR-可靠性**：WebGL context lost 恢复、自适应 DPR、滚出视口卸载。
- **NFR-安全**：参数化查询、zod 输入校验、限流、安全响应头、非 root 容器。
- **NFR-可访问性/移动端**：触控目标、字号下限、430px 宽适配。
- **NFR-性能**：几何体合并为单 draw call；标签 ~20fps 节流。
- **NFR-可维护性**：TypeScript 严格类型、CI、文档化。

## 非目标（本版不做）
真实用户账户体系大规模启用、高并发生产级集群、实时海量数据管道、付费/支付功能。

## 约束
单台腾讯云服务器（无域名/HTTPS 前），作者主力为 vivo 手机，重型构建/验收在云服务器与远程 runner 完成。
